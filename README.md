# Grammarify for desktop: releases

Installers for the Grammarify desktop app, and the feed the installed app uses to update itself.

- **macOS:** download the `.dmg` for your Mac. `arm64` is for Apple Silicon (M1 and later); the one without `arm64` is for Intel Macs.
- **Updating:** the app checks this repository on its own and shows an *Update* button in General when a newer version is here.

The source code lives in a separate, private repository.
